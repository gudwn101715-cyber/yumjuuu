# 염주 온라인 PC 테스트

[게임 테스트 ZIP 받기](yeomju-online-test.zip)

1. Node.js 24 이상을 설치합니다.
2. ZIP을 압축 해제하고 `yumjuuu` 폴더에서 터미널을 엽니다.
3. `npm ci`를 실행하고, 완료되면 `npm start`를 실행합니다.
4. Chrome 또는 Edge에서 http://localhost:3001 을 엽니다. 게임 중에는 터미널을 열어 둡니다.

ZIP에는 빌드된 클라이언트가 포함되어 있습니다. API 키는 필요하지 않습니다.
소스만 내려받은 경우에는 `npm ci` 다음에 `npm run build`를 실행해야 합니다.

두 명 접속은 일반 창과 시크릿 창에서 같은 주소와 채널을 열어 시험합니다.
