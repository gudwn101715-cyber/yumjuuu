# 염주 온라인 PC 테스트

[게임 테스트 ZIP 받기](yeomju-online-test.zip)

이번 버전은 합장과 실제 절을 분리하고, 방석 자동 이동·낮은 개인 드롭 확률·향 공양 대기줄을 추가했습니다. 성별 구분 없는 짧고 둥근 캐릭터와 맑은 산사, 게임 전용 화면을 사용합니다.

구조물 충돌과 자동 우회도 적용했으며, 목탁과 배경음은 실제 목탁 타격·사찰 염불 녹음으로 교체했습니다. 게임 메뉴에서 독경·염불을 켜거나 음원 출처를 확인할 수 있습니다.

1. Node.js 24 이상을 설치합니다.
2. ZIP을 압축 해제하고 `yumjuuu` 폴더에서 터미널을 엽니다.
3. `npm ci`를 실행하고, 완료되면 `npm start`를 실행합니다.
4. Chrome 또는 Edge에서 http://localhost:3001 을 엽니다. 게임 중에는 터미널을 열어 둡니다.

ZIP에는 빌드된 클라이언트가 포함되어 있습니다. API 키는 필요하지 않습니다.
소스만 내려받은 경우에는 `npm ci` 다음에 `npm run build`를 실행해야 합니다.

두 명 접속은 일반 창과 시크릿 창에서 같은 주소와 채널을 열어 시험합니다.

| 조작                     | 기능                                       |
| ------------------------ | ------------------------------------------ |
| WASD / Shift             | 걷기 / 빠른 걸음                           |
| 빈 화면을 누른 채 드래그 | 카메라 회전                                |
| G / 합장                 | 두 손을 모으거나 합장 풀기                 |
| Space / 절하기           | 빈 방석으로 이동해 절하기                  |
| 향 공양                  | 대기줄에 합류하고 차례대로 향 올리기       |
| F / 목탁                 | 앉은 자리의 목탁 두드리기, 본인에게만 재생 |
| I / M / Enter / Esc      | 염주함 / 지도 / 채팅 / 메뉴                |

개인 절 드롭은 기본 8%, 장비 효과를 포함해 최대 20%입니다. 합장과 향 공양은 아이템을 주지 않으며, 공동 108배 보너스는 별도입니다.
