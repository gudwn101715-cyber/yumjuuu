# 염주 온라인

**천천히 걷고, 함께 절하고, 나만의 염주를 잇는 온라인 사찰 힐링 게임.**

실제 게임 촬영: [전체 플레이 화면](docs/screenshots/gameplay.png) · [법당 안 화면](docs/screenshots/temple.png) · [캐릭터와 수행 동작](docs/screenshots/monks.png)

미리 빌드된 [PC 테스트 ZIP](downloads/yeomju-online-test.zip)은 압축을 푼 `yumjuuu` 폴더에서 `npm ci`, `npm start`를 실행한 뒤 http://localhost:3001 에서 플레이합니다. Node.js 24 이상이 필요합니다.

브라우저에서 플레이하는 첫 번째 버전입니다. React·Three.js 클라이언트와 서버 권한 방식의 WebSocket 게임 서버로 구성했습니다. 화면 속 다른 순례자는 실제 같은 채널에 접속한 사용자이며, 접속 인원이나 채팅을 가짜 데이터로 채우지 않습니다.

## 시작하기

Node.js **24 이상**이 필요합니다. 이 클라우드 환경에는 Node 24와 Chromium이 준비되어 있습니다.

```bash
cd /workspace/yumjuuu
npm ci
npm run dev
```

개발 클라이언트는 5173번, 게임 서버는 3001번 포트에서 실행됩니다. Vite가 `/api`와 `/ws`를 서버로 전달합니다. 터미널에서 Ctrl+C를 누르면 두 프로세스를 종료합니다. API 준비 상태는 `GET /api/health`로 확인할 수 있습니다.

배포용 클라이언트를 만들고 같은 출처에서 제공하려면:

```bash
npm run build
npm start
```

`npm start`는 3001번 포트에서 정적 클라이언트와 API, WebSocket을 함께 제공합니다. 외부 서비스나 API 키는 필요하지 않습니다. 서체·3D 모델·녹음 음원은 로컬에서 제공합니다. 독경·염불 배경음은 메뉴에서 선택한 뒤에만 재생합니다. 음원의 출처와 이용허락은 [음원 크레딧](docs/AUDIO-CREDITS.md)에 있습니다.

- **합장과 절:** 합장은 선 채 두 손을 모으는 별도 동작이며 보상이나 절 횟수를 주지 않습니다. 절을 누르면 빈 방석으로 자동 이동해 무릎을 꿇고 손과 이마를 낮춘 뒤 돌아옵니다. 서버도 방석 위의 절만 허용합니다. 절은 기본 4.2초이며 개인 아이템은 기본 8% 확률로 추첨합니다.
- **향 공양 대기줄:** 마당의 향로를 누르거나 향 공양을 선택하면 대기줄 입구로 이동합니다. 채널별로 입장 순서를 유지하고, 차례가 오면 향로 앞으로 이동해 6초 동안 향을 올립니다. 이동하거나 대기를 취소하면 줄에서 빠집니다. 향 공양은 아이템을 지급하지 않습니다.
- **숲의 채집:** 채집은 재료 1개를 보장하며 장소마다 8초 후 재생성됩니다.
- **공동 108배:** 채널과 법당별로 절 횟수를 합산합니다. 108회를 채우면 최근 10분 안에 그 법당에서 기여하고, 보상 시점에도 법당 주변에 있는 접속자에게 추가 재료를 지급합니다.
- **염주 조합:** 염주알 10종과 염주띠 6종, 일반·고급·희귀·영웅·전설 등급. 띠에는 8~108개의 알을 끼울 수 있습니다. 이동 속도·절 속도·발견 확률을 조합하고 다른 플레이어의 캐릭터를 눌러 염주를 구경할 수 있습니다.
- **실시간 도반과 대화:** 같은 채널의 캐릭터와 채팅을 동기화합니다. 이름을 바꾸고 채널을 옮겨도 소지품과 개인 수행 기록을 유지합니다.
- **개인 기록 보관:** HttpOnly 쿠키와 SQLite로 이름·인벤토리·장착·누적 절 횟수·향 공양 횟수를 보관합니다. 재접속·서버 재시작 후에도 복구합니다. 기존 성별 저장값은 사용하지 않습니다. 계정 가입·다른 기기로 이전·아이템 거래는 아직 없습니다.

### 플레이 화면

접속하면 전체 화면을 채운 3인칭 게임으로 바로 시작합니다. 화면에는 작은 채널 표시와 염주함·메뉴 아이콘, 수행 동작만 표시합니다. 지도·대화·프로필·능력치·설정은 필요할 때 메뉴에서 엽니다. Esc를 눌러도 게임 화면 밖의 홈페이지나 기록 화면으로 전환되지 않습니다.

빈 화면을 마우스 왼쪽 버튼으로 누른 채 드래그하면 캐릭터 주위로 시점이 돌아갑니다. 오른쪽 드래그와 터치 드래그도 지원합니다. 드래그는 이동 클릭과 구분하며 커서 잠금 버튼이나 더블 클릭은 필요하지 않습니다.

게임 메뉴에서 자동·높음·보통·낮음 화질을 선택할 수 있으며 선택은 이 브라우저에 저장됩니다. 자동은 기기의 화면 부하에 맞춰 해상도와 그림자를 조절합니다. 같은 메뉴에서 배경음과 개인 목탁 소리를 각각 설정할 수 있습니다.

카메라는 캐릭터 뒤에서 앞을 바라보는 3인칭 원근 시점입니다. 모바일에서는 화면 드래그로 둘러보고, 왼쪽 아래 방향 조작판을 누르는 동안 걸을 수 있습니다.

기본 걷기는 초당 2.8, Shift를 누른 빠른 걸음과 자동 이동은 초당 4.2 월드 단위입니다. 이동 속도 장비 효과는 여기에 곱해지며, 서버도 같은 최대 속도로 검증합니다.

**절하기**를 누르면 방석 선택·이동·착석·절을 이어서 수행합니다. 다른 도반이 먼저 자리를 차지하면 다른 빈 방석을 찾습니다. 앉아서 절을 마친 뒤 F 또는 **목탁 두드리기**를 누르면 자신의 목탁 소리만 들립니다. 같은 채널에서 한 자리를 동시에 차지할 수 없으며 이동·접속 종료·채널 이동 시 자리를 비웁니다. 다른 도반에게도 합장·절·착석·향 공양 상태가 보입니다.

한 브라우저에서 여러 창을 열면 동일한 순례자로 취급하고 마지막으로 입장한 창에 접속을 넘깁니다. 두 명을 시험하려면 서로 다른 브라우저 프로필 또는 시크릿 창을 이용하세요. 쿠키를 삭제하면 이전 기록을 찾을 수 없으므로 주의하세요.

### 재료와 능력치

소나무·대나무·단풍나무 → 향나무·대추나무 → 회양목·백단 → 자단 → 흑단·침향 순으로 게임 내 희귀도를 정했습니다. 소재의 밀도·내구성·희소성과 게임 균형을 함께 반영한 설정이며, 실제 목재의 강도 순위를 엄밀하게 나타내지는 않습니다.

띠는 삼베·무명·아마·명주·오색 금강매듭·백팔 금강염주띠로 이어집니다. 능력치는 합산하되 이동 속도 +75%, 절 속도 +200%, 발견 확률 +100%를 상한으로 적용합니다. 절 소요 시간은 `4.2초 ÷ (1 + 절 속도 / 100)`입니다.

절의 개인 드롭 확률은 `min(20%, 8% + 발견 확률 × 0.12%)`이며, 발견 확률 능력치는 희귀 이상 재료의 상대 가중치도 높입니다. 예를 들어 발견 확률 +25% 장비를 착용하면 절 드롭 확률은 11%입니다. 공동 108배 보너스는 이 개인 추첨과 별도로 지급합니다. 테마 내 아이템별 확률은 등급 가중치를 정규화한 값으로, 테마마다 후보가 달라 동일 등급의 최종 확률도 다릅니다.

## 검증

```bash
npm test
npm run build
npm run test:e2e
```

서버 통합 테스트는 실제 HTTP·WebSocket 연결을 사용합니다. 이동·거리·재생성·장착·낮은 드롭 확률·방석 전용 절·별도 합장·향 대기줄 순서와 취소·공동 보상·채널 격리·출처 검증·SQLite 복구를 확인합니다. 실제 연결 108개 입장과 109번째 거절도 별도로 확인합니다.

브라우저 테스트는 게임 전용 화면, 왼쪽 드래그, 키보드 이동, 합장과 방석 자동 절, 향 공양, 실제 캐릭터의 이마 높이, 채집→장착→재접속, 개인 목탁 소리와 모바일 조작을 확인합니다. 시스템 Chromium이 없으면 `npx playwright install chromium`을 실행하세요. 별도 Chromium 경로는 `PLAYWRIGHT_CHROMIUM_PATH`로 지정할 수 있습니다. 테스트가 필요한 개발 서버를 자동으로 실행합니다.

## 구조와 다음 단계

그래픽은 성별 구분 없는 작고 둥근 스님, 승복·가사와 걷기·합장·오체투지·착석 애니메이션, 입체 기와·공포·창살·현판과 금빛 불단을 가진 법당, 맑은 푸른 하늘과 푸른 산 능선으로 구성했습니다. 목재·석재·기와·흙·천의 표면은 로컬에서 생성합니다. 돌·나무 바닥과 계단의 겹치는 면을 제거하고, 흙길 교차부의 높이와 지면 장식의 깊이를 분리해 깜빡임을 방지합니다.

정적 월드는 재질과 공간 구역별로 병합해 UV와 시야 밖 객체 제거를 유지합니다. 카메라 충돌은 세밀한 기와 전체 대신 단순한 건물 충돌체로 계산합니다. 멀리 있거나 혼잡한 원격 캐릭터는 병합 모델로 전환하고, 가까운 도반 최대 8명과 본인에게 관절 애니메이션을 적용합니다. 픽셀 밀도는 1.5배로 제한하고 그림자는 초당 최대 20회 갱신합니다. 이 선택들은 비용을 줄이기 위한 구현이며, 1,080명 동시 플레이의 프레임 성능을 입증하는 부하 시험은 아닙니다.

```text
src/                 React 화면, Three.js 월드, 연결·배경음
src/world/           캐릭터·법당·자연환경·표면 재질
src/moktakAudio.js   해당 브라우저에서만 재생하는 목탁 녹음
public/audio/        목탁·사찰 독경 녹음과 출처·이용허락
shared/game.js       테마·법당·채집 지점·아이템·장비 능력치
shared/templeLayout.js 법당·108개 방석·목탁·향로·대기줄 좌표
shared/worldCollision.js 공통 충돌체·이동 해석·자동 이동 경로
server/index.js      HTTP·WebSocket, 게임 규칙, SQLite
tests/              서버 통합 및 실제 브라우저 테스트
```

현재 **서버 한 프로세스 안의 논리 채널 10개**입니다. 서버 10대를 배포한 구성은 아닙니다. 1,080명의 지속적인 동시 플레이 성능은 아직 검증하지 않았습니다. 서버가 보상·속도·거리·정원을 검증하고, 10Hz 동기화·입력 제한·느린 연결 차단을 적용했습니다. 클라이언트는 정적 사찰 모델을 재질별로 병합하고 캐릭터 모델을 재사용하며 픽셀 밀도를 제한합니다.

공개 운영 전에는 채널별 룸 서버 분리, 관심 영역·변경분 동기화, 계정 인증과 공용 DB, 운영 도구, HTTPS와 부하 검증이 필요합니다. 상세한 서버 구성·환경 변수·백업 주의사항은 [서버 문서](server/README.md)에 있습니다.

충돌은 게임에 필요한 고정 구조물을 단순한 도형으로 표현합니다. 작은 풀·꽃·장식까지 물리 연산을 적용하지는 않습니다. NPC·거래·퀘스트·추가 의상은 다음 확장 대상으로 남겨 두었습니다. 공동 절 진행률·채집 재생성 타이머·채팅·자리 점유·향 대기줄은 메모리에 있으며 서버 재시작 시 초기화됩니다.
